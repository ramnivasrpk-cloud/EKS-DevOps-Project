# Production Grade DevOps Project

This project demonstrates a production-ready Kubernetes deployment using:

- AWS EKS
- Terraform
- Docker
- GitHub Actions
- Prometheus
- Grafana
- NGINX Ingress
- Trivy Security Scan

## Features

- Automated Infrastructure Provisioning
- CI/CD Pipeline
- Kubernetes Deployment
- Monitoring Stack
- Security Scanning
- Production Best Practices

## Deployment Steps

1. Run Terraform
2. Configure kubectl
3. Install ingress controller
4. Install monitoring stack
5. Push code to GitHub
6. Pipeline deploys automatically
